Security Scan Hub

2026

Seven good open-source security tools come with seven setups and seven report formats. Security Scan Hub runs the ones you pick in a single scan and merges the results into one Security Inbox, with the highest-severity findings first and a clear record of which tools completed, were skipped, or failed. Reports export as HTML, JSON, and SARIF. It runs locally as a command-line tool and as a desktop app; the desktop prerelease is available for Apple silicon and Intel Macs as signed, notarized downloads (and through Homebrew), and for Windows through the Microsoft Store or an unsigned portable build.

GitHub Download

What it does

  • Seven integrations: Google OSV Scanner, NVIDIA SkillSpector, OpenAI Codex Security, Alibaba Open Code Review, OpenAI PHP2Shell Checker, the Cloudflare Security Audit Skill, and Anthropic's Defending Code reference harness
  • Checks dependencies for known vulnerabilities, scans AI agent skills for suspicious patterns, reviews source code, and checks a URL's response headers
  • Security Inbox: search by package, title, or advisory ID, filter by severity, and read each finding's impact, affected version, and listed fix
  • Saved scans and comparisons, with the original evidence and metadata one click away
  • AI-backed tools run only with explicit opt-in, since they may send code or context to the configured provider
  • Desktop app bundles OSV Scanner, so a first scan needs no terminal, no Node.js, and no account; all seven tools run on a supported Mac after setup, and the Cloudflare and Anthropic workflows are off on Windows
  • English and Korean interface, with a narrow layout that keeps search, filters, and scroll position when you go back to results

Tech stack

A Node.js 22 command-line orchestrator (ES modules, tested with the built-in Node test runner) that launches each upstream tool, normalizes its output, and records coverage and provenance per tool. The desktop app wraps it in Electron and ships the bundled OSV Scanner. Mac releases are Developer ID-signed and notarized, with SHA-256 checksums for every download.
