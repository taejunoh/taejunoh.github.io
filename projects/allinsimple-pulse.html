AllinSimple Pulse

2026

AllinSimple Pulse monitors websites, APIs, cron jobs, and workers. It runs HTTP checks and accepts authenticated heartbeat pings, confirms an outage with retries before opening a single incident, records the recovery, and sends Down and recovery alerts to Email, Telegram, Discord, and Slack. It is a private pilot and signup is closed.

Website

What it does

  • HTTP checks against a status code, a piece of text, or a typed value inside nested JSON
  • Heartbeat pings for cron jobs and workers, authenticated, with a set interval and a grace period
  • Retries confirm an outage before it counts, so one outage opens one incident
  • Recovery is recorded on the incident when the check passes again
  • Down and recovery alerts to Email, Telegram, Discord, and Slack, each tested end to end

Sibling: AllinSimple Desk

AllinSimple Desk is a personal operations ledger for many projects: links, recurring costs, renewal dates, and maintenance tasks, in Korean and English. A read-only demo with fictional data is public, with an English version. It is built with React 19, Vite, and SQLite, and has not yet been validated in real use.

Tech stack

Next.js 16 and React 19 with Tailwind CSS 4. Drizzle ORM over PostgreSQL, which coordinates due checks, retries, and incidents. A separate worker process runs the checks. Tests use Vitest.
