AllinSimple Desk

2026

AllinSimple Desk is a personal operations ledger for keeping project links, recurring costs, renewal dates, and maintenance tasks together. The local app supports Korean and English, stores its ledger in SQLite, and includes JSON backup and restore.

English demo 한국어 데모

What it does

  • Groups project links, recurring costs, renewal dates, and maintenance tasks
  • Records confirmed charges separately from recurring cost estimates
  • Supports JSON backup and restore
  • Provides a public read-only demo with fictional data

The local MVP runs on one computer, with a separate public demo for exploring fictional project records.

Sibling projects

AllinSimple Pulse monitors uptime and heartbeats. AllinSimple Check is a local prototype for a fixed browser flow.
