Seoul Rising

2026

K-pop news often reaches US fans after Korea has already moved on. Seoul Rising is an iOS widget and a small app that shows what is rising in Korea first. A Python pipeline watches YouTube channel feeds, Wikipedia pageviews, and Yonhap, Soompi, and Koreaboo headlines, scores artist momentum, and flags when Korea moves before English-language coverage. Every 30 minutes a GitHub Actions job writes one static trends.json to GitHub Pages. There is no server, no accounts, and no API keys. Version 1.0.0 was submitted to App Review on October 17, 2026.

Website GitHub

What it does

  • Reads YouTube channel feeds, Wikipedia pageviews, and headlines from Yonhap, Soompi, and Koreaboo, all without API keys
  • Scores each artist's momentum from those sources
  • Flags an artist when Korea moves before English-language coverage does
  • Writes one static trends.json every 30 minutes through GitHub Actions and serves it from GitHub Pages
  • Shows the results in an iOS 18 app and a WidgetKit home-screen widget that read the file
  • Falls back to the cached copy, then to bundled sample data, when the file cannot be fetched

Tech stack

Python 3.12 with httpx and uv, SQLite, and GitHub Actions on a 30-minute schedule that publishes to GitHub Pages. The iOS 18 app is SwiftUI with a WidgetKit extension sharing data through an App Group, and the project is generated with xcodegen.
